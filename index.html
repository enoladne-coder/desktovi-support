快速開始

  1. 讓裝置位於可互通的網路Mac 與控制端須在相同內網，或透過您自行設定的 VPN 互通。桌隨不提供中繼連線服務。
  2. 建立身分並配對在兩端建立裝置身分。iPhone 可掃描 Mac 的配對碼，比對兩端確認碼後確認配對。Windows 使用身分管理工具交換公開憑證並核對指紋。
  3. 在 Mac 開始分享選擇本機 IP 與連接埠（預設 5906），依系統提示授權螢幕擷取，再按「開始分享」。正式候選版啟動時不會自動分享。
  4. 從控制端連線連線後預設僅觀看。Mac 允許操作後，再於控制端選擇「操作 Mac」。本機 F12／Fn+F12 可收回操作。

常見問題

連不上 Mac，先檢查什麼？

確認 Mac 已開始分享、IP 與連接埠相同、兩端已配對，且網路允許裝置互通。iPhone 須允許區域網路權限。一次只允許一台 Client 連線，請先中斷其他裝置。

看得到桌面，卻不能操作？

連線預設僅觀看。請在 Mac 確認輔助使用、輸入監控與操作授權，再於 Client 切換「操作 Mac」。本機按過 F12 或權限失效後，需要重新授權。

如何傳送或接收檔案？

先在 Mac 停止分享並選擇接收資料夾，再重新開始分享與連線。檔案傳輸需要操作授權，每次一個一般檔案、最大 1 GiB；資料夾請先壓縮。同名檔案不會被覆寫。

iPhone 收到的檔案存在哪裡？

檔案先保留在 App 的 Received 資料夾。可按「儲存到檔案」另存副本，或在 iPhone「檔案」App 的本機 App 資料夾管理。返回桌面不會自動刪除已接收檔案。

Windows 需要另外安裝 Java 嗎？

內附 Java 25 的 Windows x64 ZIP 不需要另行安裝 Java。請完整解壓縮並保留 runtime、lib 等檔案，再執行 run-client.bat。身分管理請先關閉 Client，再執行 identity-client.bat。請依組織的安全政策使用。
